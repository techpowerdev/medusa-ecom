## ตาราง map (กฎ 22a) — ไม่มีจุดที่เข้ากฎ 22b/22c ในขอบเขต
- text-small-regular → text-xs leading-5 font-normal (12px/20px/400) — 12 จุด
- text-small-semi    → text-xs leading-5 font-semibold (12px/20px/600) — 1 จุด (ลิงก์กลับตะกร้าใน layout ของ checkout)
- text-base-regular  → text-sm leading-6 font-normal (14px/24px/400) — 6 จุด
- text-base-semi     → text-sm leading-6 font-semibold (14px/24px/600) — 1 จุด (ชื่อในตัวเลือกที่อยู่ที่บันทึกไว้)
- text-2xl-semi      → text-[30px] leading-[48px] font-semibold (30px/48px/600) — 2 จุด (not-found ของ checkout และ cart)
ตรวจทุกจุด: ไม่มี class อื่นที่ไม่มี variant ตั้ง font-size/line-height/font-weight บน element เดียวกัน (มีแค่สี, uppercase, layout);
จุดเดียวที่อยู่ใน cn(...) คือกรอบ payment-container ร่วมกับ border/rounded/hover:border-ring/border-primary (ไม่ชนกลุ่มฟอนต์)
