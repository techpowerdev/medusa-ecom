# SFUI-8 — floating label (spec 09 กฎ 23, AC-22, AC-23, AC-25)
ฐาน: e2a3ffa9 (b2b27ccc + docs รอบ 45) · Node 22.23.3 · Tailwind 4.3.5 · storefront prod build (`next build` + `next start`) · Playwright --workers=1

## การแก้
- globals.css: ลบ rule `input:focus ~ label, input:not(:placeholder-shown) ~ label { @apply -translate-y-3 text-xsmall-regular }`
  และ `input:focus ~ label { @apply left-0 transition-all duration-300 }` (ไม่เหลือ token 13 ตัวใน rule ป้ายลอย)
- common/components/input: `peer` ใน className ของ `Input` จาก ui/ (ไม่แก้ ui/*); label ได้
  `peer-focus:{-translate-y-3,text-[10px],leading-4,font-normal,left-0,transition-all,duration-300}` +
  `peer-not-placeholder-shown:{-translate-y-3,text-[10px],leading-4,font-normal}` (ค่าตรง ไม่ใช้ token)
- ยืนยัน compile (Tailwind 4.3.5, CSS ใน .next/static/chunks/*.css):
  `.peer-not-placeholder-shown\:text-\[10px\]:is(:where(.peer):not(:placeholder-shown)~*){font-size:10px}` (ทำนองเดียวกันทุก class)
  `.peer-focus\:duration-300:is(:where(.peer):focus~*){--tw-duration:.3s;transition-duration:.3s}`; selector `~ label` แบบไม่กำกับใน CSS ที่ compile = 0
- ไม่มีผู้เรียก `<Input>` ที่ส่ง className (ซึ่งจะทับ `peer`) — ตรวจทุกไฟล์ที่ import common/components/input

## label ที่ selector เดิมจับ (document.querySelectorAll ของ `input:focus ~ label` ∪ `input:not(:placeholder-shown) ~ label`)
หน้าที่ตรวจ (ลูกค้า login + cart 1 ชิ้น เว้นแต่ระบุ): /th/account (ยังไม่ login: login + register), /th, /th/store, PDP /th/products/t-shirt, /th/cart,
/th/checkout?step=address|delivery|payment|review (delivery–review ใช้ cart ที่พร้อมจ่าย — RadioGroup ใน form), /th/account, /orders, /profile,
/addresses, /vouchers, /th/search?q=shirt, /th/contact, /th/g/<token> (team และ pool)

| PDP | option-button L/M/S (text-small-regular) | radio.sr-only | 10px/16px/400, translate 0px -12px | 12px/20px/400, translate none |
| PDP | label ที่ครอบ product-quantity-select (text-small-regular) | input hidden ×2 | 10px/16px/400, translate 0px -12px | 12px/20px/400, translate none |
| /th/g/<token> team, pool | option-button L/M/S (component เดียวกับ PDP) | radio.sr-only | 10px/16px/400, translate 0px -12px | 12px/20px/400, translate none |
| checkout step=address | ป้ายลอย "อีเมล" (ค่าเติมจากบัญชี) | email | 10px/16px/400, 0px -12px, left 0px | เท่าเดิม |
| account/profile | ป้ายลอย "ชื่อ", "นามสกุล" (ค่าเติม) | text | 10px/16px/400, 0px -12px, left 0px | เท่าเดิม |
- หน้าอื่นที่ตรวจ: ไม่พบ label ที่ selector จับ (Checkbox ของ common/components/checkbox ห่อ input ซ่อนของ Radix ใน <span> แล้ว — SFUI-5a;
  RadioGroup ของ checkout delivery/payment และ store refinements ไม่มี <label> พี่น้องหลัง input) → ไม่มี label ใดที่ค่าหลังไม่ตรง className ของตัวเอง
