## สาเหตุที่พบ
- (a) ฟอร์มเพิ่ม/แก้ที่อยู่ใช้ `<form action={fn}>` → React 19 reset ฟอร์มหลัง action แม้ล้ม และ server action ที่ตอบ 500 ทำให้ promise ฝั่ง client reject → ใช้ `submitWithoutReset` (CORE-23b) + `withActionFallback` (ใหม่)
- (b) ที่อยู่ใบเสร็จ: action ล้มระดับ network → `useActionState` โยนเข้า error boundary ("This page couldn't load") → ห่อด้วย `withActionFallback` แสดง error ไทยในฟอร์ม
- (c) `AccountInfo.handleToggle` เปิด panel ผ่าน `setTimeout(100)` → 100ms แรกช่องยังอยู่ใต้ `inert` ตัวอักษรที่พิมพ์หาย → เปิดทันที
- (d) ลิงก์ `/customer-service` ไม่มีหน้า (prefetch ได้ 404 `/th/customer-service`) → `/contact`
- (e) `getRegion(...).catch(() => null)` ใน `addPendingToCart` (review #150) → `console.error` ก่อนคืน null
